Atmo 1.4.0

Atmo 1.4 adds built-in automatic updates, so this is the last release you need to download by hand.

New

  • Automatic updates — Atmo now keeps itself up to date via Sparkle. On first launch you'll be asked whether to check for updates automatically; you can change this any time in Settings → Updates
  • Check for Updates… — check on demand from the Atmo menu

Requires macOS 13 or later.
